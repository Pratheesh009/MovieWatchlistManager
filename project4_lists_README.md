# Movie Watchlist Manager – Lists and Data Management

## Overview
This R project demonstrates how to create and work with lists in R, using a movie-watchlist example.

## Objectives
- Create a list containing related pieces of information.
- Access list elements by name or position.
- Add, update, or inspect list items where implemented.

## Requirements
- R (version 4.0 or later recommended)
- RStudio (optional)

## How to Run
1. Install and open R or RStudio.
2. Open `project4_lists.R`.
3. Run the script.

## Concepts Covered
- Creating lists with `list()`
- Named list elements
- Accessing list elements using `$`, `[[ ]]`, or `[ ]`

## Project Files
- `project4_lists.R` — main R script
